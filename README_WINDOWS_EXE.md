# راهنمای اجرای نسخه دسکتاپ ویندوز و ساخت فایل اجرایی (`*.EXE`)

این سامانه به صورت کامل برای اجرا در ویندوز ۷، ۱۰ و ۱۱ به صورت آفلاین طراحی شده است:

## روش ۱: ساخت تک‌فایل اجرایی بومی `SoilNailDesignSuite1.0.exe` (۱۰۰٪ آفلاین در ۲ ثانیه)
1. در پوشه اصلی پروژه روی فایل **`build-portable-exe.bat`** دو بار کلیک کنید.
2. اسکریپت با استفاده از `scripts/pack-assets.cjs` کل فایل‌های برنامه را فشرده کرده و با کامپایلر بومی ویندوز (`csc.exe`) درون یک فایل تکی **`release\SoilNailDesignSuite1.0.exe`** جاسازی می‌کند.
3. فایل تولیدشده کاملاً مستقل (Portable) است و بدون نیاز به پوشه جانبی یا اینترنت اجرا می‌شود.

## روش ۲: اجرای فوری آفلاین بدون کامپایل
روی فایل **`start-offline-app.bat`** دو بار کلیک کنید تا برنامه در پنجره مستقل دسکتاپ (App Mode) باز شود.

## روش ۳: نصب مستقیم روی دسکتاپ ویندوز (PWA)
از نوار ابزار بالای نرم‌افزار یا نوار آدرس مرورگر Edge/Chrome گزینه **«نصب نرم‌افزار»** را بزنید تا آیکون آن روی دسکتاپ و منوی Start ویندوز ایجاد گردد.
